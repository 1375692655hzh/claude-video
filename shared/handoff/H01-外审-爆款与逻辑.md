## 本频道最优先的结构标准：前紧中稳后强（YouTube 长视频；其他平台删掉本节和下面的 A0）

公式：前紧中稳后强 + 情绪穿插 + 数据反转 + 提问引导。视频最怕流水账，要像过山车一样有起伏。目标时长 15–25 分钟，按约 150 英文词 / 分钟估算时间。

| 段 | 20 分钟片的位置（其他时长按占比） | 要求 |
|---|---|---|
| S1 强钩子开场 | 0:00–0:30，≤ 75 词 | **前 10 秒（≤ 25 词）**直接给最震撼的数据或大悬念，不铺垫；“你以为…其实…”句式后面必须紧跟具体数字。**前 30 秒**要有一个具体的主悬念（完整答案留到 S4）和一句具体的“看完能得到什么”（最多 3 样）。五要素：钩子、利害、信源、好处、悬念 |
| S2 背景设定 | 0:30–3:00，≤ 12% | 用最快的时间把事情说清楚、建立共识；结尾点出共识可能错在哪 |
| S3 硬核拆解 | 3:00–15:00，≈ 55–60% | 用图表和数据支撑观点；分 3–4 个模块，**每 3–4 分钟（450–600 词）换一种讲法**（数据算账 / 对手或同行对比 / 历史对照 / 案例 / 反方 / 持仓推演），相邻模块不能同一种；至少一个竞争对手对比；每 3 分钟有一块“糖”（新画面或新段子） |
| S4 高潮反转 | 15:00–20:00，≈ 20–25% | 抛出一条多数观众不知道、但有出处的隐藏信息，推翻或改写 S2 的共识，或回答 S1 的悬念；不能编数字，口播不说“没人知道”，直接说出处；反转后落回对持仓的意义 |
| S5 收尾与互动 | 最后 ≤ 2 分钟 | 给出明确判断 → 观众能站队的具体留言问题（“你怎么看？留言告诉我”）→ **明确喊订阅**（一句直接的话，不用 smash that like button 套话）→ 免责声明；不软收尾；全片订阅提醒共 2 次（中段 1 + 结尾 1） |
