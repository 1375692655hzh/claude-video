你在给一份视频**初稿**做外部审稿。请把自己当成目标平台的资深观众和编辑，不要替作者编造事实。

我会附上：
1. `00-项目设置.md`：人设、平台、画幅、目标时长和选题来源
2. 人设文件：身份、受众、表达风格和经历边界
3. `01-初稿.md`：需要审的初稿
4. 所选平台规范：标题 / 钩子、结构、句长、信源和合规要求

请按下面格式回答，指出问题时引用原句；平台规范有编号时同时写编号。

## 1. 事实与定位
- 是否有事实、数字、引用、信源或判断强度问题；哪些必须回原始资料核实。
- 是否符合人设、目标观众和所选平台，不要把它改成另一个平台的长稿或短稿。

## 2. 标题 / 首帧与开头
- 标题、首帧字卡和开头是否兑现同一个核心钩子，是否逐级增加信息。
- 逐句标出开头功能：钩子 / 利害 / 信源 / 追问 / 无功能。
- 给一个改写版本；只能使用初稿已有且可核实的事实和数字。

## 3. 结构与留存（YouTube 长视频：前紧中稳后强，最优先）
- 按规范〇.5 画一张时间轴表：S1 强钩子开场 / S2 背景设定 / S3 硬核拆解 / S4 高潮反转 / S5 收尾与互动，每段写稿中起止句、词数、按语速估算的时间，判定合格 / 不合格。
- 前 10 秒是否直接给最震撼的数据或悬念；前 30 秒是否有具体主悬念（答案在 S4）和一句具体好处。
- 每 3–4 分钟有没有换一种讲法（数据算账 / 对手对比 / 历史对照 / 案例 / 反方 / 持仓推演）；哪一段最像流水账。
- 每个模块有没有挂在事实上的情绪钩子；S4 有没有一条有出处的隐藏信息改写共识；结尾有没有判断 + 站队式问题 + 明确喊订阅。

## 4. 正文与留存
- 列出最可能流失观众的 3 个位置，引用原句，说明原因和具体改法。
- 是否有一个视频只讲一件事的聚焦度（短视频），或章节节拍与递进（长视频）。

## 5. 语言与去 AI 味
- 列出书面腔、翻译腔、营销腔、假对比、三连排比、空泛拔高和模板化收尾，给具体改法。
- 不要抹掉人设原有的语气，不要添加主持人没有的经历或观点。

## 6. 建议清单
用表格输出：原句 / 问题 / 建议改法 / 理由 / 是否需要事实核查。
最后单列“标准本身可能不合理的地方”。只给具体建议，不确定的地方明确说不确定。
