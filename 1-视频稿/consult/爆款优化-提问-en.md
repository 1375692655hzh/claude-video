## 1. 事实与一致性
- 有中文底稿时，逐章核对数字换算、遗漏或新增事实、判断强度；只列有问题的。
- 没有中文底稿时，只核初稿内部一致性和已有来源，不臆造“原文”。
- 点名的信源是否合规；哪些内容必须回公司一手资料或允许的信源核实。

## 2. 标题 / 首帧与开头
- 是否兑现同一个钩子，开头有没有寒暄、模板句或无关自我介绍。
- 逐句标功能：钩子 / 利害 / 信源 / 追问 / 无功能。
- 给一版符合所选平台长度与句长规则的英文改写，事实和数字只能来自初稿。

## 3. 结构与留存（YouTube 长视频：前紧中稳后强，最优先）
- 按规范〇.5 画一张时间轴表：S1 强钩子开场 / S2 背景设定 / S3 硬核拆解 / S4 高潮反转 / S5 收尾与互动，每段写稿中起止句、词数、按语速估算的时间，判定合格 / 不合格。
- 前 10 秒是否直接给最震撼的数据或悬念；前 30 秒是否有具体主悬念（答案在 S4）和一句具体好处。
- 每 3–4 分钟有没有换一种讲法（数据算账 / 对手对比 / 历史对照 / 案例 / 反方 / 持仓推演）；哪一段最像流水账。
- 每个模块有没有挂在事实上的情绪钩子；S4 有没有一条有出处的隐藏信息改写共识；结尾有没有判断 + 站队式问题 + 明确喊订阅。

## 4. 英文是否地道
- 列出翻译腔、AI 腔或不像英语财经观众常用说法的句子（最多 10 处），给英文改写。
- 检查财经术语、数字读法、主语和判断强度；不要添加主持人没有的经历、比喻或观点。

## 5. 正文与平台适配
- 最可能流失观众的 3 个位置，原因和改法。
- 是否符合该平台的信息密度与结构；不要把 Shorts / Reels / TikTok 拉成长视频，也不要把长视频切成没有解释的短句集合。
