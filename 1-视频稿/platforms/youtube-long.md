# YouTube 长视频爆款标准（中文财经 / 科技）

适用：横屏 8–20 分钟的中文财经科技解说（频道「Andy港美观察」，主持人 Andy，港美股投资 10 年以上）。
这份标准用于两处：第 1 步「爆款优化」逐条对照修改；「发布包装」按它写标题、封面、简介、置顶评论。
**重点是标题和开头**：标题 + 封面决定有没有人点进来（点击率），开头 30 秒决定点进来的人留不留下（留存）。

> 版本 v2（2026-10-28）：Claude 起草 → agy（Gemini 4 Argon High）评审 → 合成。评审原文和取舍见
> `consult/记录/2026-10-28-标准初版评审.md` 和文末修订记录。数字是起步值，跑完几期后按后台数据调整。

## 一、标题

### 1. 硬性要求（不满足就不能用）

| # | 要求 | 说明 |
|---|---|---|
| T1 | **长度 18–26 个字宽，硬上限 28** | 字宽按显示宽度算：1 个汉字 / 全角标点 = 1；**2 个**英文字母、数字或半角符号 = 1（`CoreWeave` 约 4.5，`10月23日` 约 4）。手机推荐流两行大约显示 22–26 个字宽 |
| T2 | **前 12 个字宽出现强认知主体 + 冲突或数字** | 强认知主体：观众不用搜就知道的公司、人物、事件（英伟达、微软、台积电、巴菲特、鲍威尔、美联储）。前 20 个字宽内把悬念讲完整 |
| T3 | **不用弱认知实体** | 协会缩写、分析师英文名、二三线供应商（CASPA、Dylan Patel、揖斐电）不进标题和封面；换成身份或利益标签（"华尔街半导体分析师""英伟达最大客户""5 倍市盈率的存储股"）。检查：标题里需要搜索才知道是谁的词，数量必须是 0 |
| T4 | **视频必须兑现** | 标题里的问题、数字、结论，正文要明确回答；开头 30 秒内开始兑现。不兑现的标题党一律不用 |
| T5 | **一个核心钩子，允许有因果的复合** | 允许"具体事实 / 数据 + 反常识冲突或利益落点"这种有因果的组合（"一边狂买 GPU、一边自研替代，英伟达的高毛利还能守多久？"）；不允许把两个无关噱头并排（"5 大财富密码！英伟达的对手竟是最大客户？"） |
| T6 | **禁用词** | 营销腔：震惊、重磅、刚刚、速看、史诗级、财富密码、散户必看、主力慌了、一定要看完；连续感叹号；emoji；【】超过 1 组 |
| T7 | **合规** | 不承诺收益（稳赚、必涨、翻倍股），不点名喊买卖；讲个股用"逻辑""风险""线索"这类词 |
| T8 | **代码和英文名** | 主体是美股公司时，标题或简介前两行带上英文名或代码（`英伟达 NVDA`），方便搜索和推荐给对的观众 |

### 2. 钩子类型（选一个当核心）

| 类型 | 适合的内容 | 例 |
|---|---|---|
| 反常识 / 冲突 | 结论和大众认知相反 | 英伟达最大的客户，为什么在自研芯片替代它？ |
| 利益 / 损失 | 关系到观众的持仓和风险 | 存储股市盈率只有 5 倍，便宜还是陷阱？ |
| 悬念 / 算账 | 抛问题、给出账面矛盾 | 微软一年砸 800 亿建机房，钱从哪里赚回来？ |
| 清单 | 多条线索、盘点（清单里要有强认知主体） | AI 算力链 5 个最容易踩的坑 |
| 时效 / 关键事件 | 财报、议息、重大发布 | 微软谷歌亚马逊同周财报，美联储决议撞上 PCE |
| 人物观点 | 有分量的人说了什么（用身份标签） | 华尔街半导体分析师：AI 利润正在换手 |

### 3. 和封面的分工
- **封面大字 4–6 个字，只负责冲突或情绪**（"大客户反水？"）；**标题负责具体信息和因果**。两者讲同一个钩子，不重复同一句话。
- 封面画面要有**具象的对立**（左边英伟达机柜，右边谷歌 TPU，中间一个反差数字），不要只放一张意义不明的机房背景。
- 检查：缩到手机推荐流大小（宽 168px）、遮住标题，1.5 秒内能看清大字、看懂是谁和什么冲突。
- 尺寸 1280×720，主体和大字避开右下角（时长标签）。

### 4. 交付方式
- 每期 **5–8 个候选标题**，按钩子类型分组，标注字宽和强认知主体。
- 选 **3 个推荐**，用于 YouTube「测试与比较」（Test & Compare，最多 3 个标题 / 缩略图组合），写清理由。
- 用下面的评分表给推荐的 3 个打分，低于 7 分的不推荐。

### 5. 标题评分表（每项 0–2 分，满分 10）

| 项 | 0 分 | 1 分 | 2 分 |
|---|---|---|---|
| 具体性 | 没有具体元素，或有弱认知实体 | 有强认知主体 | 强认知主体 + 数字或冲突 |
| 钩子强度 | 陈述句，没有好奇点 | 有好奇点但常见 | 让人"想知道答案"或"觉得和我的持仓有关" |
| 前 12 字宽 | 关键信息在后半段 | 前 12 字宽有主体但没冲突 | 前 12 字宽就有主体 + 冲突 / 数字 |
| 兑现度 | 正文答不上 | 正文有答案但在很后面 | 开头 30 秒就开始兑现 |
| 干净度 | 有 T6 禁用词或两个无关噱头 | 稍长（> 26 字宽）或符号偏多 | 简洁、口语、无夸张 |

## 二、开头（前 25–28 秒，约 120–135 字口播）

MiMo 冰糖约 290 字 / 分钟，再留出数字停顿和转场，开头控制在 135 字以内。

### 1. 结构（三段）

| 时间 | 字数 | 段落 | 要做到 |
|---|---|---|---|
| 0–6 秒 | 25–30 字 | **钩子** | 第一句就是全片最强的信息：强认知主体 + 反常识冲突或具体数字；**直接兑现标题的点击理由** |
| 6–16 秒 | 45–50 字 | **利害 + 反差数字** | 和观众的持仓、判断有什么关系；用"你"（"你手里的芯片股""你以为 5 倍市盈率很便宜"）；给 1–2 个反差数字 |
| 16–28 秒 | 45–55 字 | **一句话信源 + 核心追问，直接进第一章** | 信源嵌在句子里一句带过（"伯恩斯坦的半导体分析师刚在会上算了一笔账"）；最后一句是第一章要回答的问题 |

### 2. 硬性要求

| # | 要求 |
|---|---|
| H1 | 第一句不能是寒暄、自我介绍、"今天我们来聊聊""最近很多人问我"、背景铺垫 |
| H2 | 前 6 秒出现标题里的核心主体（标题说英伟达，第一句就有英伟达） |
| H3 | **前 60 秒口播不说"欢迎来到 / 我是 Andy"**；频道和资历改成画面左下角的名片条（0:08–0:15 出现约 4 秒，文案"Andy｜10年港美股投资"），由第 2 步脚本标注 |
| H4 | **不报目录**：前 30 秒不出现超过 2 项的并列预告（"今天拆出五条线索：一……二……三……"） |
| H5 | 不讲历史背景、不下定义、不在前 30 秒堆英文人名和机构全称（中英混杂 TTS 听感差，人名放画面字幕条） |
| H6 | 每句 ≤ 25 字，一句一个信息；口播读出来不拗口 |
| H7 | 前 15 秒不用模糊指代（"最大客户""某算力商""两位分析师"）；题材和公司有关时，前 100 字至少点出 2 个具体公司名（宏观题材如美联储、非农不适用） |
| H8 | 前 30 秒不用 AI 连接废话：更值得注意的是、众所周知、不可否认、这背后的逻辑是、今天我们从……拆出；删掉后句意不变的连接词一律删 |

### 3. 开头自检
把开头逐句标上功能（钩子 / 利害 / 信源 / 追问 / 无功能），**"无功能"的句子删掉或后移**；数一下字数是否 ≤ 135。

### 4. 交给第 2 步的画面要求（写进视频稿备注，由脚本落实）
- 前 5 秒至少 2 次视觉信息递进（如 0–2 秒冲突大字卡 → 2–5 秒巨头产品 / 人物画面），同一静态画面不超过 2.5 秒；
  静音只看画面和字幕也能看懂核心冲突。
- 名片条的出现时间（H3）。

## 三、正文与留存

- **双层节拍**：
  - **小节拍，每 35–45 秒（约 170–210 字）**：一次注意力刷新——算账举例、图表变化、反方观点、一个具体数字的"翻译"。
  - **大钩子，每 2–2.5 分钟（约 550–700 字，一般在章节交界）**：给出本章结论后，用一个推翻顺向思维的转折问题引出下一章。
  - 不要每 60 秒硬卖关子，会打断算账逻辑、显得像营销号。
- **章节**：按观众的问题分章（"大客户为什么要研究替代方案？"），章节名用于 YouTube 时间戳和第 2 步分镜。
- **数据要有翻译**：每个关键数字后面跟一句"这意味着什么"。
- **观点要有立场**：每章结尾给明确判断（"我的判断是……"），并说清风险或反方观点。
- **中段订阅提醒**：放在第一个高价值结论之后（约全片 30–40% 处），一句话。
- **结尾**：3 句以内总结 → 一个可执行的看法或观察指标 → 引到下一个相关视频或评论区问题；
  不用"感谢观看 / 下期再见"作为唯一结尾，核心结论不能留到结尾才第一次讲。
- **长度**：MiMo 冰糖约 290 字 / 分钟；10 分钟约 2800–3000 字。

## 四、发布包装（审核通过后）

| 项 | 要求 |
|---|---|
| 标题 | 见第一节；候选 + 3 个推荐 + 评分 |
| 封面 | 见第一节第 3 条；每期 2–3 版对应推荐标题，qwen-image 生成底图 / 主体，大字后期叠加 |
| 简介 | **前两行约 100 字：钩子 + 中英文公司名和代码**（搜索和"展开前"只显示这里，对推荐影响大）；接着 3–5 行概要；**时间戳章节**（第一个必须是 0:00）；参考资料；免责声明「本视频仅供信息分享，不构成任何投资建议」；末尾 3–5 个 #标签 |
| 置顶评论 | 二选一：① 观众能站队的问题（"你觉得自研芯片会不会真的抢走英伟达订单？"）② 补充资料、勘误、数据来源；不要只写"欢迎订阅" |
| 后台标签 | 5–10 个就够（YouTube 已大幅降低标签权重，主要用于拼写纠错）：中英文公司名、代码、常见错拼 |

## 五、爆款优化的两道工序（第 1 步第 2 阶段）

1. **Claude 按本标准改**：逐条对照第一 ~ 三节修改初稿，写 `02-爆款优化.md`，末尾附修改清单和标题评分。
2. **agy 给第二意见**：`npm run consult -- consult/爆款优化-提问.md --file <期名>/02-爆款优化.md --file platforms/youtube-long.md --out <期名>/02b-agy建议.md`。
   Claude 逐条处理：**采纳合理的，驳回不合理的并写理由**。特别注意 agy 改写里**没有出处的数字和事实不能采用**（要么核实，要么删），
   以及它自己用上的营销词。合成结果写回 `02-爆款优化.md`。
