# YouTube 长视频爆款标准（中文财经 / 科技）

适用：横屏 8–20 分钟的中文财经科技解说（频道「Andy港美观察」，主持人 Andy，港美股投资 10 年以上）。
这份标准用于两处：第 1 步「爆款优化」逐条对照修改；「发布包装」按它写标题、封面、简介、置顶评论。
**重点是标题和开头**：标题 + 封面决定有没有人点进来（点击率），开头 30 秒决定点进来的人留不留下（留存）。

## 怎么读这份标准

| 标记 | 含义 | 能不能改 |
|---|---|---|
| **〔官方〕M** | YouTube 官方帮助里写明的机制，是事实，附来源 | 不能改；YouTube 改了规则才更新 |
| **〔必须〕T / H / P** | 本频道的硬规则，从官方机制和研究推出来；不满足就不能用 | 只在复盘有数据后改，写进修订记录 |
| **〔建议〕** | 优先这样做；有理由时可以不做，在修改清单里写明理由 | 随时补充 |

数字（字宽、字数、秒数）都是起步值，跑完几期后按后台数据调整。
句式模板和示例见 `templates/标题与开头句式.md`；交付前用第七节的自检清单逐项打勾。

> 版本 v3（2026-10-29）。v2 经 agy 评审；v3 补了官方依据、按"官方 / 必须 / 建议"三层重排，
> 研究和评审原文见 `consult/记录/2026-10-28-标准初版评审.md`、`consult/记录/2026-10-29-标题开头研究*.md`。

## 〇、依据

### 官方机制（YouTube 帮助中心，2026-10-29 查证）

| # | 机制 | 对我们意味着什么 | 来源 |
|---|---|---|---|
| M1 | 标题要准确；标题和内容不符，观众会中途离开，影响视频被发现 | 标题党会被推荐系统反噬 → T4 | [Thumbnail & title tips](https://support.google.com/youtube/answer/12340300) |
| M2 | 标题要简短，重要的词放前面；集数、品牌放末尾；少用全大写和 emoji | → T1、T2、T10 | 同上 |
| M3 | 标题有两种取向：可搜索（说清内容）或激发好奇 | → 先判断话题型 / 事件型（第一节建议 1） | 同上 |
| M4 | 表现最好的视频 90% 用自定义封面；标题和封面一起被观众看到 | 封面和标题是一个整体，要分工 | 同上 |
| M5 | 「测试与比较」最多测 3 个标题、3 个封面或组合；**按观看时长份额判胜负**（不是点击率）；结果为胜出 / 表现相同 / 无结论，**无结论时用第一个上传的选项**；一般两周内完成，可以提前停止或手动选定 | 能骗点击但留不住人的标题会输；**最有把握的标题放第一个** | [A/B test titles & thumbnails](https://support.google.com/youtube/answer/16391400) |
| M6 | 「前 30 秒留存」是官方分析指标；低说明标题封面和内容对不上，或开头方式要改 | 开头首要任务是兑现点击理由 → H1、H2 | [Key moments for audience retention](https://support.google.com/youtube/answer/9314415) |
| M7 | 曝光量大（比如上了首页）时点击率自然偏低；不同流量来源的点击率不能直接比；一半的频道和视频点击率在 2%–10% | 复盘不能只看点击率 → 第五节 | [Impressions & CTR](https://support.google.com/youtube/answer/7628154) |
| M8 | 简介里的时间戳可生成章节：第一个必须是 0:00，至少 3 个，每章至少 10 秒 | → P3 | [Video chapters](https://support.google.com/youtube/answer/9884579) |
| M9 | 标题、封面、简介比标签重要得多；标签在发现中作用很小，主要用于常见错拼 | 标签 5–10 个就够 → P5 | [Tags](https://support.google.com/youtube/answer/146402) |
| M10 | 可以给标题和简介加翻译，按观众的语言设置显示 | 可做繁体版（第四节建议） | [Translate titles & descriptions](https://support.google.com/youtube/answer/4792576) |

### 外部研究（参考，不是因果）

- **R1** AIR Media Tech 2026 标题研究（18,080 个英文频道，11 个类目，用互动率衡量）：30–50 个英文字符最好，90+ 明显变差；
  商业 / 科技类数字、具体金额效果强，问号效果强（前提是观众本来就有这个问题）；作者说明是相关性。
  英文 30–50 字符约等于 15–25 个中文字宽，但中文标题要塞主体 + 代码 + 数字 + 冲突，所以下限取 16。
- **R2** 经验判断（agy 评审）：中文港美股观众对"没人告诉你的""揭秘"这类神秘感词已有戒心；手机首页会静音自动播放开头几秒，
  观众点之前可能已经看到开头。这两条没有数据，只作为建议的理由。
- 网上流传的"30 秒留存 70% 算好""前 5 秒钩子提升 40% 留存"等数字找不到原始数据，**不使用**。

## 一、标题

### 1. 〔必须〕硬性要求

| # | 要求 | 说明 |
|---|---|---|
| T1 | **长度 16–26 个字宽，硬上限 28；常规写 18–26** | 字宽按显示宽度算：1 个汉字 / 全角标点 = 1；**2 个**英文字母、数字或半角符号 = 1（`NVDA` 约 2，`10月23日` 约 4）。16–17 只用于单主体极简反差句 |
| T2 | **前 12 个字宽出现强认知主体 + 冲突或数字**；事件型可以是"前 8–10 字宽搜索词 + 冒号后具体冲突" | 强认知主体：不用搜就知道的公司、人物、事件（英伟达、微软、台积电、巴菲特、鲍威尔、美联储） |
| T3 | **弱认知实体为 0** | 协会缩写、分析师英文名、二三线供应商（CASPA、Dylan Patel、揖斐电）换成身份或利益标签（"华尔街半导体分析师""英伟达最大客户"） |
| T4 | **视频必须兑现**（M1、M5） | 标题里的问题、数字、结论正文要明确回答，开头 30 秒内开始兑现 |
| T5 | **一个核心钩子，允许有因果的复合** | 可以"具体事实 + 反常识冲突或利益落点"；不能把两个无关噱头并排 |
| T6 | **禁用词** | 营销腔：震惊、重磅、刚刚、速看、史诗级、财富密码、散户必看、主力慌了、一定要看完；**神秘感好奇词**：没人告诉你的真相、绝密、内幕曝光、揭秘；连续感叹号；emoji；【】超过 1 组。**允许**有数据锚定的好奇（"财报里被忽略的 XX 指标""华尔街真正在算的账"） |
| T7 | **合规** | 不承诺收益（稳赚、必涨、翻倍股），不点名喊买卖 |
| T8 | **代码和英文名** | 美股公司在标题或简介第一行带代码（`英伟达 NVDA`）；港股数字代码一般不进标题，放简介前两行 |
| T9 | **金额带币种** | 写"800 亿美元""300 亿港元"，不写孤立的"800 亿" |
| T10 | **频道名不进标题；固定栏目名放末尾**（M2） | 如"…｜美股一周前瞻"，仍受 28 字宽上限约束 |
| T11 | **问句只问观众已经在问的问题**（R1） | 持仓的人本来就在想的（"便宜还是陷阱？""钱从哪赚回来？"）；不问"底层逻辑是什么""如何看待某趋势" |

### 2. 〔建议〕做法

1. **先判断这期是话题型还是事件型**（M3）
   - 话题型（观点、算账、反常识，主要靠首页和推荐）：钩子优先，主体放前 12 字宽。
   - 事件型（财报、议息、非农、重大发布，搜索 + 推荐都有）：搜索词放最前，冒号后接具体冲突，**不能写成说明文**
     （「美联储 11 月议息：降不降息，对美股意味着什么」不合格）。
2. **具体胜过泛泛**（R1）：数字、金额、倍数、具体公司；能点名两个巨头就别用"大客户"一类关系词。
3. **数字带对比标尺**：跟历史比、跟同行比、投入产出比（"只有 5 倍市盈率""砸 800 亿美元只换回 XX 亿收入"）。
4. **财经问句优先两类**：账面算不过来的悖论（"钱从哪赚回来？"）、持仓两难（"便宜还是陷阱？"）。
5. **用词贴近港美股投资者**："数据中心 / 算力 / 资本开支"比"机房 / 基建"准确。

### 3. 钩子类型（选一个当核心）

| 类型 | 适合的内容 | 例 |
|---|---|---|
| 反常识 / 冲突 | 结论和大众认知相反 | 英伟达最大的客户，为什么在自研芯片替代它？ |
| 利益 / 损失 | 关系到观众的持仓和风险 | 存储股市盈率只有 5 倍，便宜还是陷阱？ |
| 悬念 / 算账 | 账面矛盾 | 微软一年砸 800 亿美元建数据中心，钱从哪赚回来？ |
| 清单 | 多条线索、盘点（要有强认知主体） | AI 算力链 5 个最容易踩的坑 |
| 事件 | 财报、议息、重大发布 | 美联储 11 月议息：通胀反弹，鲍威尔还会降息吗？ |
| 人物观点 | 有分量的人说了什么（用身份标签） | 华尔街半导体分析师：AI 利润正在换手 |

（例句里的数字只示意句式，用时以稿件为准。）

### 4. 和封面、开头的分工

- **〔必须〕三级递进，不重复**：封面大字（4–6 字，冲突或情绪）→ 标题（主体 + 矛盾，具体信息和因果）→ 开头第一句（标题没写的公司名、数字或动作）。
  三者讲同一个钩子，但每一级都要多给一层信息。
- 〔建议〕封面画面要有**具象的对立**（左边英伟达机柜、右边谷歌 TPU、中间一个反差数字），不要只放意义不明的机房背景。
- 〔建议〕检查：缩到手机推荐流大小（宽 168px）、遮住标题，1.5 秒内能看清大字、看懂是谁和什么冲突。
- 〔必须〕尺寸 1280×720，主体和大字避开右下角（时长标签）。

### 5. 交付和评分

- 每期 **5–8 个候选标题**，按钩子类型分组，标注字宽和强认知主体。
- 选 **3 个推荐**用于「测试与比较」：**3 个要用不同钩子类型**（只换几个字测不出差别）；**最有把握的放第一个**（M5：无结论时用第一个）。
- 推荐的 3 个按下表打分，低于 7 分的不推荐。

| 项（每项 0–2 分，满分 10） | 0 分 | 1 分 | 2 分 |
|---|---|---|---|
| 具体性 | 没有具体元素，或有弱认知实体 | 有强认知主体 | 强认知主体 + 数字或冲突 |
| 钩子强度 | 陈述句、说明文，没有好奇点 | 有好奇点但常见 | 让人"想知道答案"或"觉得和我的持仓有关" |
| 前 12 字宽 | 关键信息在后半段 | 有主体但没冲突 | 主体 + 冲突 / 数字（事件型：搜索词 + 冒号后冲突） |
| 兑现度 | 正文答不上 | 有答案但在很后面 | 开头 30 秒就开始兑现 |
| 干净度 | 有 T6 禁用词或两个无关噱头 | 稍长（> 26 字宽）或符号偏多 | 简洁、口语、无夸张 |

## 二、开头（前 25–28 秒，≤ 135 字口播）

MiMo 冰糖约 290 字 / 分钟，再留出数字停顿和转场，开头控制在 135 字以内。

### 1. 〔必须〕硬性要求

| # | 要求 |
|---|---|
| H1 | 第一句不能是寒暄、自我介绍、"今天我们来聊聊""最近很多人问我"、背景铺垫 |
| H2 | **第一句是钩子，兑现标题并多给一层信息**（标题没写的具体公司名、数字或动作）；不原样重读标题（M6） |
| H3 | 前 60 秒口播不说"欢迎来到 / 我是 Andy"；频道和资历改成画面左下角名片条（0:08–0:15 出现约 4 秒，"Andy｜10年港美股投资"），由第 2 步脚本标注 |
| H4 | 不机械报目录（"今天分五点：第一……第二……"）；清单型和一周前瞻可以在开头最后一句**用一句话串起不超过 3 个看点** |
| H5 | 不讲历史背景、不下定义；英文人名和机构全称不进前 30 秒口播（放画面字幕条） |
| H6 | **逗号分句 ≤ 20 字，整句 ≤ 40 字**，一句只讲一层意思；读出来不拗口 |
| H7 | 不用"某大厂""某神秘资金"这类盲盒词；第一句可以用"最大客户"这类关系标签承接标题，但**前 15 秒内必须点名**；公司类题材前 100 字至少 2 个具体公司名（美联储、非农等宏观题材不适用） |
| H8 | 不用 AI 连接废话：更值得注意的是、众所周知、不可否认、这背后的逻辑是、问题是、今天我们从……拆出；删掉后句意不变的连接词一律删 |
| H9 | **四个要素必须齐**：钩子、和观众的利害、信源、核心追问；**第一句是钩子，最后一句是进第一章的追问**，中间顺序可以灵活 |
| H10 | 事件型开头可以第一句给出结论方向，但**下一句必须用"但 + 关键变量"抛出反差**，不能一开头把底牌亮完 |

### 2. 〔建议〕做法

- **默认节奏**：0–6 秒钩子（25–30 字）→ 6–16 秒利害 + 反差数字（45–50 字）→ 16–28 秒信源 + 追问（45–55 字）。
  连续几期都一样会有套路感，可以把信源嵌进第一句（"摩根士丹利刚算了一笔账：……"）。
- **利害面向一类持仓**，不只面向一只股票（"只要你持有美股 AI 股"比"如果你手里有英伟达"覆盖更多人）。
- **数字说清口径**：毛利率还是毛利额、营收占比还是利润占比、哪个财年 / 季度；口播里含糊的数字比没有数字更伤信任。
- **信源一句带过**："伯恩斯坦的半导体分析师刚在行业会上算了这笔账"；人名放字幕条。
- **追问落到投资者利益**：不只是"能替代多少"，而是"会抢走多少订单、利润流向谁"。
- **自检**：逐句标功能（钩子 / 利害 / 信源 / 追问 / 无功能），"无功能"的句子删掉或后移；数字数 ≤ 135。

### 3. 〔必须〕交给第 2 步的画面要求（写进视频稿备注）

- 前 5 秒至少 2 次视觉信息递进（如 0–2 秒冲突大字卡 → 2–5 秒巨头产品 / 人物画面），同一静态画面不超过 2.5 秒；
  静音只看画面和字幕也能看懂核心冲突（R2：首页静音自动播放）。
- 名片条的出现时间（H3）。

## 三、正文与留存（〔建议〕，第 2 阶段对照）

- **双层节拍**：
  - **小节拍，每 35–45 秒（约 170–210 字）**：一次注意力刷新——算账举例、图表变化、反方观点、一个具体数字的"翻译"。
  - **大钩子，每 2–2.5 分钟（约 550–700 字，一般在章节交界）**：给出本章结论后，用一个推翻顺向思维的转折问题引出下一章。
  - 不要每 60 秒硬卖关子，会打断算账逻辑、显得像营销号。
- **章节**：按观众的问题分章，**章节名带公司名或业务关键词**（"谷歌 TPU 能替代多少英伟达 GPU？"，不写"替代比例测算"），
  用于 YouTube 章节（M8）和第 2 步分镜。
- **数据三要素**：金额带币种；估值、增速、股价带时间基准（"按 2026 财年三季报""未来 12 个月市盈率"）；
  关键数字带对比标尺，并跟一句"这意味着什么"。
- **观点要有立场**：每章结尾给明确判断（"我的判断是……"），并说清风险或反方观点。
- **中段订阅提醒**：放在第一个高价值结论之后（约全片 30–40% 处），一句话。
- **结尾**：3 句以内总结 → 一个可执行的看法或观察指标 → 引到下一个相关视频或评论区问题；
  核心结论不能留到结尾才第一次讲。
- **长度**：MiMo 冰糖约 290 字 / 分钟；10 分钟约 2800–3000 字。

## 五、发布后复盘（〔建议〕，每期填进 `<期名>/05-复盘.md`）

- **四项联看**（M7）：24 小时内首页 / 推荐的曝光量、点击率、前 30 秒留存、平均观看比例。曝光扩大时点击率下降是正常的，不要单看点击率判断标题好坏。

## 七、自检清单（复制到 `02-爆款优化.md` 末尾逐项打勾）

**标题（每个推荐标题都过一遍）**
- [ ] T1 16–28 字宽（常规 18–26）
- [ ] T2 前 12 字宽：强主体 + 冲突 / 数字（事件型：搜索词 + 冒号后冲突）
- [ ] T3 弱认知实体 = 0
- [ ] T4 正文能兑现，开头 30 秒开始兑现
- [ ] T5 只有一个核心钩子
- [ ] T6 无禁用词、无神秘感好奇词
- [ ] T7 不承诺收益、不喊买卖
- [ ] T8 美股带代码（标题或简介第一行）
- [ ] T9 金额带币种
- [ ] T10 没有频道名；栏目名在末尾
- [ ] T11 问句是观众已经在问的
- [ ] 3 个推荐钩子类型不同，最有把握的排第一，均 ≥ 7 分
- [ ] 封面大字 → 标题 → 开头第一句逐级多一层信息

**开头**
- [ ] H1 第一句不是寒暄、自我介绍、背景
- [ ] H2 第一句兑现标题并比标题多一层信息
- [ ] H3 口播没有"欢迎来到 / 我是 Andy"，名片条已备注
- [ ] H4 没有机械报目录（清单型 ≤ 3 个看点、一句话）
- [ ] H5 没有历史背景、定义、英文全称
- [ ] H6 分句 ≤ 20 字、整句 ≤ 40 字
- [ ] H7 前 15 秒已点名；公司类题材前 100 字 ≥ 2 个公司名
- [ ] H8 没有 AI 连接废话
- [ ] H9 钩子 / 利害 / 信源 / 追问齐全，首句钩子、末句追问
- [ ] H10 事件型：给方向后紧接"但 + 关键变量"
- [ ] ≤ 135 字；逐句功能标注里没有"无功能"
- [ ] 前 5 秒画面要求已写进备注

**正文和包装**
- [ ] 每 35–45 秒有小节拍，每 2–2.5 分钟有大钩子
- [ ] 章节名带公司名或关键词
- [ ] 数字带币种 / 时间基准 / 对比标尺
- [ ] 每章有"我的判断"
- [ ] 简介章节 0:00 开始、≥ 3 个、每章 ≥ 10 秒
