# YouTube 长视频爆款标准（中文财经 / 科技）

适用：已确认人设的横屏财经科技深度解说，**目标时长 15–25 分钟**（v4 起；更短的片只在用户明确要求时做，仍按〇.5 的占比走五段）。
**v4 起最高优先级是〇.5「前紧中稳后强」结构**（10 秒抓人、30 秒设悬念、全程干货或情绪钩子、结尾强引导互动）；本文其他条目和它冲突时以〇.5 为准。
默认发布英文视频：本文的通用部分（官方机制、章节、节拍、数据三要素、封面、复盘）照用；标题、开头、包装等语言相关的规则用于中文底稿，
发布用的英文稿和英文包装以 `youtube-long-en.md` 为准。用户直接交付英文成稿时不强制补中文底稿。
这份标准用于工作流③初稿、④外部建议、⑤成稿，以及附加的发布包装。
**重点是标题和开头**：标题 + 封面决定有没有人点进来（点击率），开头 30 秒决定点进来的人留不留下（留存）。

## 怎么读这份标准

| 标记 | 含义 | 能不能改 |
|---|---|---|
| **〔官方〕M** | YouTube 官方帮助里写明的机制，是事实，附来源 | 不能改；YouTube 改了规则才更新 |
| **〔必须〕T / H / P** | 本频道的硬规则，从官方机制和研究推出来；不满足就不能用 | 只在复盘有数据后改，写进修订记录 |
| **〔建议〕** | 优先这样做；有理由时可以不做，在修改清单里写明理由 | 随时补充 |

数字（字宽、字数、秒数）都是起步值，跑完几期后按后台数据调整。
句式模板和示例见 `templates/标题与开头句式.md`；交付前用第七节的自检清单逐项打勾。

> 版本 v4（2026-11-10）：按同事方法论新增〇.5 核心结构，用户定为 YouTube 长视频最优先标准。v3（2026-10-29）补了官方依据、按"官方 / 必须 / 建议"三层重排，
> 研究和评审原文见 `consult/记录/2026-10-28-标准初版评审.md`、`consult/记录/2026-10-29-标题开头研究*.md`；v4 的审核记录见 `consult/记录/2026-11-10-开头与结构审核.md`。

## 〇、依据

### 官方机制（YouTube 帮助中心，2026-10-29 查证）

| # | 机制 | 对我们意味着什么 | 来源 |
|---|---|---|---|
| M1 | 标题要准确；标题和内容不符，观众会中途离开，影响视频被发现 | 标题党可能在测试里输给能留住人的标题；v5 起只做提示，由用户权衡 | [Thumbnail & title tips](https://support.google.com/youtube/answer/12340300) |
| M2 | 标题要简短，重要的词放前面；集数、品牌放末尾；少用全大写和 emoji | → T1、T2、T10 | 同上 |
| M3 | 标题有两种取向：可搜索（说清内容）或激发好奇 | → 先判断话题型 / 事件型（第一节建议 1） | 同上 |
| M4 | 表现最好的视频 90% 用自定义封面；标题和封面一起被观众看到 | 封面和标题是一个整体，要分工 | 同上 |
| M5 | 「测试与比较」最多测 3 个标题、3 个封面或组合；**按观看时长份额判胜负**（不是点击率）；结果为胜出 / 表现相同 / 无结论，**无结论时用第一个上传的选项**；一般两周内完成，可以提前停止或手动选定 | 能骗点击但留不住人的标题会输；**最有把握的标题放第一个** | [A/B test titles & thumbnails](https://support.google.com/youtube/answer/16391400) |
| M6 | 「前 30 秒留存」是官方分析指标；低说明标题封面和内容对不上，或开头方式要改 | 开头首要任务是兑现点击理由 → H1、H2 | [Key moments for audience retention](https://support.google.com/youtube/answer/9314415) |
| M7 | 曝光量大（比如上了首页）时点击率自然偏低；不同流量来源的点击率不能直接比；一半的频道和视频点击率在 2%–10% | 复盘不能只看点击率 → 第五节 | [Impressions & CTR](https://support.google.com/youtube/answer/7628154) |
| M8 | 简介里的时间戳可生成章节：第一个必须是 0:00，至少 3 个，每章至少 10 秒 | → P3 | [Video chapters](https://support.google.com/youtube/answer/9884579) |
| M9 | 标题、封面、简介比标签重要得多；标签在发现中作用很小，主要用于常见错拼 | 标签 5–10 个就够 → P5 | [Tags](https://support.google.com/youtube/answer/146402) |
| M10 | 可以给标题和简介加翻译，按观众的语言设置显示 | 可做繁体版（第四节建议） | [Translate titles & descriptions](https://support.google.com/youtube/answer/4792576) |

### 外部研究（参考，不是因果）

- **R1** AIR Media Tech 2026 标题研究（18,080 个英文频道，11 个类目，用互动率衡量）：30–50 个英文字符最好，90+ 明显变差；
  商业 / 科技类数字、具体金额效果强，问号效果强（前提是观众本来就有这个问题）；作者说明是相关性。
  英文 30–50 字符约等于 15–25 个中文字宽，但中文标题要塞主体 + 代码 + 数字 + 冲突，所以下限取 16。
- **R2** 经验判断（agy 评审）：中文港美股观众对"没人告诉你的""揭秘"这类神秘感词已有戒心；手机首页会静音自动播放开头几秒，
  观众点之前可能已经看到开头。这两条没有数据，只作为建议的理由。
- 网上流传的"30 秒留存 70% 算好""前 5 秒钩子提升 40% 留存"等数字找不到原始数据，**不使用**。

## 〇.5、核心结构：前紧中稳后强（v4，最高优先级，只约束 YouTube 长视频）

> 来源：同事方法论，2026-11-10 用户定为 YouTube 长视频的首要标准。公式：**前紧中稳后强 + 情绪穿插 + 数据反转 + 提问引导**。
> 视频最怕流水账，要像坐过山车一样有起伏。这是经验方法论，不是 YouTube 官方数据；时间点是起步值，复盘时按「前 30 秒留存」（M6）和留存曲线的掉点调整。

### 1. 〔必须〕五段结构 S1–S5（以 20 分钟为基准，其他时长按占比换算）

| 段 | 20 分钟片 | 占比 | 英文词数（≈150 词/分） | 做什么 | 怎么做 |
|---|---|---|---|---|---|
| **S1 强钩子开场** | 0:00–0:30 | 固定 30 秒 | ≤ 75 | 用最震撼的数据或悬念开场 | 10 秒抓人、30 秒设悬念并说清好处，见下面 O1–O4 和第二节 |
| **S2 背景设定** | 0:30–3:00 | ≤ 12%，最长 3 分钟 | ≈ 300–375 | 用最快的时间把事情说清楚，建立共识 | 只交代理解后文必需的事实：发生了什么、市场怎么反应、大家的共识是什么；结尾点出“这个共识可能哪里错” |
| **S3 硬核拆解** | 3:00–15:00 | ≈ 55–60% | ≈ 1650–1800 | 用图表和数据支撑观点 | 拆成 3–4 个模块，每个 3–4 分钟；**至少一个模块是和竞争对手 / 同行 / 历史的对比**，用对比制造张力 |
| **S4 高潮反转** | 15:00–20:00 | ≈ 20–25% | ≈ 600–750 | 抛出多数观众不知道的隐藏信息，制造情节反转 | 见下面 D1–D3；兑现 S1 埋下的悬念 |
| **S5 收尾与互动** | 20:00–结束 | ≤ 2 分钟 | ≈ 150–300 | 给出判断，强引导互动 | 见下面 C1–C4 |

- 换算示例：15 分钟片 S2 ≈ 0:30–2:15、S3 ≈ 2:15–11:00、S4 ≈ 11:00–14:00、S5 ≈ 14:00–15:00；25 分钟片同理放大（S2 仍不超过 3 分钟，多出来的时间给 S3 加一个模块）。
- 视频稿里每段开头标 `【S1 强钩子开场】`…`【S5 收尾与互动】`（不口播），并写预计词数和预计起止时间；章节名照第三节写（带公司名或关键词），一个段可以含几个章节。外审（H01）和脚本阶段据此核对。
- **前紧中稳后强**：前段信息最密（S1–S2 不铺垫、不绕弯）；中段稳定输出干货（S3 可以慢下来算账，但不能连续 3 分钟同一种讲法）；后段比中段更强（S4 的信息量和情绪强度要高于 S3 任何一个模块，S5 不能软收尾）。

### 2. 〔必须〕S1：10 秒生死线 + 30 秒留人

| # | 要求 |
|---|---|
| O1 | **前 10 秒（英文 ≤ 25 词 / 中文 ≤ 45 字，通常 1–2 句）直接说重点：最震撼的数据，或一个大悬念**；不能是背景、定义、寒暄、预告。可以用“你以为…？其实…”的反认知句式，但“其实”后面必须紧跟具体数字或事实（「你以为苹果靠卖 iPhone 赚钱？它 [X]% 的毛利来自服务」可以；只写“其实你亏大了”不行，T4 / T7） |
| O2 | **前 30 秒设一个主悬念（open loop）**：一个具体的、观众想知道答案的问题，**完整答案留到 S4 揭晓**（S3 可以部分回答）。悬念必须具体（“英伟达为什么同时投了买方和被收购方？”），不能是“看到最后你就知道了”（H8-en 禁用 `Make sure to watch until the end`） |
| O3 | **前 30 秒告诉观众看完能得到什么好处**：一句话、最多点 3 样，必须具体（一笔算清楚的账、一个判断框架、三个观察信号、一份持仓检查清单）。这一句不算 H4 的“机械报目录”；“今天分五点”仍然禁止 |
| O4 | 第二节 H9 的四要素在长视频里变为**五要素：钩子（O1）、利害、信源、好处（O3）、悬念（O2）**；首句是钩子，末句是悬念或进 S2 的追问 |

### 3. 〔必须〕中段节奏：每 3–4 分钟换一次结构

| # | 要求 |
|---|---|
| R1 | **每 3–4 分钟切一次内容结构**（一个模块，英文约 450–600 词 / 中文约 870–1160 字）；切换点在稿里标 `‖切换：<新模块类型>‖`（不口播），脚本阶段在这里换场景、版式或画面类型 |
| R2 | **相邻两个模块不能用同一种讲法**。可选类型：数据算账 / 对手或同行对比 / 历史对照 / 具体案例或小故事（哪家公司、谁、做了什么）/ 反方观点 / 观众持仓场景推演 |
| R3 | **每 3 分钟至少给一块“糖”**：一个新画面类型，或一个新段子（具体案例、把反常数字翻译成生活里的量、一句有画面感的比喻）；不能连续 3 分钟只有平铺直叙 |
| R4 | 第三节的小节拍（每 35–45 秒一次注意力刷新）继续有效，管模块内部；R1 管模块之间的换挡 |

### 4. 〔必须〕情绪穿插（全程干货或情绪钩子）

| # | 要求 |
|---|---|
| E1 | **每个模块至少一个情绪钩子**：惊讶（反常数字）、担忧（持仓风险）、紧迫（时间窗口、催化剂日期）、爽感（账算清楚了、看穿了）、释然（风险没想象的大）；全片不能只有一种情绪 |
| E2 | **情绪必须挂在事实上**：每个情绪点紧跟数字、事件或原话；不夸大、不制造恐慌，不用 T6 禁用词，不承诺收益（T7） |
| E3 | **情绪曲线像过山车**：S1 高 → S2 稍降（建立共识）→ S3 每个模块小起伏 → S4 全片最高点 → S5 落到判断和行动；稿件末尾附一行情绪曲线（每段一个词） |

### 5. 〔必须〕数据反转（S4）

| # | 要求 |
|---|---|
| D1 | S4 必须有一条**隐藏信息**：多数观众不知道、但有出处的数据或事实（财报附注、10-Q / 电话会里不显眼的一句、供应链或持仓数据、被遗忘的历史先例、对手的同类数字）。它要**推翻或明显改写 S2 建立的共识**，或给 O2 的悬念一个出乎意料的答案 |
| D2 | 隐藏信息照样过信源规则（`../AGENTS.md`「信源规则」）；**不能为了反转编数字、拔高判断**；口播不说“没人知道 / 没人告诉你”（T6），直接说出处（“这个数字在 10-Q 第 47 页的附注里”） |
| D3 | 反转之后马上落回“这对你的持仓意味着什么”，不能只为戏剧效果；**核心结论不能等到 S4 才第一次出现**，S4 是改写或加深，不是第一次给答案 |
| D4 | 不能把 S4 的隐藏信息提前在 S1 说穿：S1 只抛问题（O2），答案留给 S4 |

### 6. 〔必须〕提问引导与强引导互动（S5 + 中段）

| # | 要求 |
|---|---|
| C1 | S5 先给**明确判断**（「我的判断是…」/ `My take:`），再抛一个**观众能站队的具体问题**引导留言：“你怎么看？留言告诉我”；二选一或三选一最好（“你会在这个价位买 A、等 B，还是都不碰？”） |
| C2 | **结尾必须明确喊订阅**：一句直接的话，例：「想看更多这样的拆解，就点个订阅」/ `Want more breakdowns like this? Subscribe.`；可以接一句下期理由（“财报出来我会重算这笔账”）。不用 `smash that like button` 一类套话 |
| C3 | 中段订阅提醒保留（第一个高价值结论之后，约全片 30–40%），一句话；**全片订阅提醒共 2 次**（中段 1 + 结尾 1），不再多 |
| C4 | 结尾不能软收尾（“今天就到这里”“that's it for today”）；顺序：判断 → 留言问题 → 订阅 → 免责声明 |

### 7. 和其他规则的关系

- 第二节开头规则 H1–H10 继续有效，O1–O4 是加强；冲突时以 O1–O4 为准（H9 四要素 → O4 五要素；H4 不报目录，但允许 O3 一句好处）。
- 第三节“不要每 60 秒硬卖关子”仍然有效：只埋一个主悬念（O2）；S3 各模块末尾的转折问题是自然过渡，不是“下面更精彩”。
- 本节只约束 YouTube 长视频；Shorts / Reels / TikTok 仍按各自平台规范。英文稿的词数、例句见 `youtube-long-en.md`。

## 一、标题

> **v5（2026-11-10 用户定）：标题没有死规则，以极致流量为目标，标题党可以用。**
> 本节所有条目（T1–T11、钩子类型、评分表）都降为**〔参考〕打法库**：想用就用，不用不需要写理由，外审和自检都不再按它们判“不合格”。
> 后面章节引用的 T4 / T6 / T7（兑现、禁用词、不承诺收益）**只约束口播和画面，不约束标题**。
>
> **首选打法：爆款标题公式**（冲突感 + 强烈情绪 + 开放性问题；为什么… / 背后的真相 / 这才是真实的… / 被低估的… / 数据对比 / 暗示收益 六类），见 `templates/标题与开头句式.md` 第〇节；**建议 28–60 字符**，中文标题可中英混搭。长视频和 Shorts 通用。
>
> **只做提示、不做拦截的两件事（由用户自己权衡）**：
> - YouTube 官方：标题和内容不符时观众会中途离开，「测试与比较」按观看时长份额判胜负（M1、M5），所以“骗点击但留不住人”的标题在测试里会输，复盘看前 30 秒留存（M6）。
> - YouTube 社区准则「垃圾内容、欺骗行为和诈骗」把“用标题、封面、简介让观众误以为内容是别的东西”列为违规（[政策原文](https://support.google.com/youtube/answer/2801973)）；夸张可以，但标题说的事视频里要有，避免被限流或下架。

### 1. 〔参考〕常用写法（原 v3 硬性要求，现仅作参考）

| # | 要求 | 说明 |
|---|---|---|
| T1 | **长度 16–26 个字宽，硬上限 28；常规写 18–26** | 字宽按显示宽度算：1 个汉字 / 全角标点 = 1；**2 个**英文字母、数字或半角符号 = 1（`NVDA` 约 2，`10月23日` 约 4）。16–17 只用于单主体极简反差句 |
| T2 | **前 12 个字宽出现强认知主体 + 冲突或数字**；事件型可以是"前 8–10 字宽搜索词 + 冒号后具体冲突" | 强认知主体：不用搜就知道的公司、人物、事件（英伟达、微软、台积电、巴菲特、鲍威尔、美联储） |
| T3 | **弱认知实体为 0** | 协会缩写、分析师英文名、二三线供应商（CASPA、Dylan Patel、揖斐电）换成身份或利益标签（"华尔街半导体分析师""英伟达最大客户"） |
| T4 | **视频必须兑现**（M1、M5） | 标题里的问题、数字、结论正文要明确回答，开头 30 秒内开始兑现 |
| T5 | **一个核心钩子，允许有因果的复合** | 可以"具体事实 + 反常识冲突或利益落点"；不能把两个无关噱头并排 |
| T6 | **禁用词** | 营销腔：震惊、重磅、刚刚、速看、史诗级、财富密码、散户必看、主力慌了、一定要看完；**神秘感好奇词**：没人告诉你的真相、绝密、内幕曝光、揭秘；连续感叹号；emoji；【】超过 1 组。**允许**有数据锚定的好奇（"财报里被忽略的 XX 指标""华尔街真正在算的账"）；**允许**「你以为…？其实…」反认知句式，前提是标题或开头紧跟具体数字（〇.5 O1） |
| T7 | **合规** | 不承诺收益（稳赚、必涨、翻倍股），不点名喊买卖 |
| T8 | **代码和英文名** | 美股公司在标题或简介第一行带代码（`英伟达 NVDA`）；港股数字代码一般不进标题，放简介前两行 |
| T9 | **金额带币种** | 写"800 亿美元""300 亿港元"，不写孤立的"800 亿" |
| T10 | **频道名不进标题；固定栏目名放末尾**（M2） | 如"…｜美股一周前瞻"，仍受 28 字宽上限约束 |
| T11 | **问句只问观众已经在问的问题**（R1） | 持仓的人本来就在想的（"便宜还是陷阱？""钱从哪赚回来？"）；不问"底层逻辑是什么""如何看待某趋势" |

### 2. 〔参考〕做法

1. **先判断这期是话题型还是事件型**（M3）
   - 话题型（观点、算账、反常识，主要靠首页和推荐）：钩子优先，主体放前 12 字宽。
   - 事件型（财报、议息、非农、重大发布，搜索 + 推荐都有）：搜索词放最前，冒号后接具体冲突，**不能写成说明文**
     （「美联储 11 月议息：降不降息，对美股意味着什么」不合格）。
2. **具体胜过泛泛**（R1）：数字、金额、倍数、具体公司；能点名两个巨头就别用"大客户"一类关系词。
3. **数字带对比标尺**：跟历史比、跟同行比、投入产出比（"只有 5 倍市盈率""砸 800 亿美元只换回 XX 亿收入"）。
4. **财经问句优先两类**：账面算不过来的悖论（"钱从哪赚回来？"）、持仓两难（"便宜还是陷阱？"）。
5. **用词贴近港美股投资者**："数据中心 / 算力 / 资本开支"比"机房 / 基建"准确。

### 3. 钩子类型（选一个当核心）

| 类型 | 适合的内容 | 例 |
|---|---|---|
| 反常识 / 冲突 | 结论和大众认知相反 | 英伟达最大的客户，为什么在自研芯片替代它？ |
| 利益 / 损失 | 关系到观众的持仓和风险 | 存储股市盈率只有 5 倍，便宜还是陷阱？ |
| 悬念 / 算账 | 账面矛盾 | 微软一年砸 800 亿美元建数据中心，钱从哪赚回来？ |
| 清单 | 多条线索、盘点（要有强认知主体） | AI 算力链 5 个最容易踩的坑 |
| 事件 | 财报、议息、重大发布 | 美联储 11 月议息：通胀反弹，鲍威尔还会降息吗？ |
| 人物观点 | 有分量的人说了什么（用身份标签） | 华尔街半导体分析师：AI 利润正在换手 |

（例句里的数字只示意句式，用时以稿件为准。）

### 4. 封面（v6，2026-11-10 用户定；YouTube 长视频和 Shorts 通用）

> **核心：极致对比 + 情绪张力 + 可读性强 + 主体视觉突出。封面不是艺术品，是路边小广告：显眼！**
> **分工**：Claude 负责**封面文案（选哪几个字）和提示词**；画面设计（构图、配色、主体、人物动作、背景）交给生图模型自由发挥，提示词只给方向，**不写过于约束的版式要求**。

**① 封面大字（Claude 定）**
- **字少而大、夸张**：中文**不超过 15 个字**，英文封面**不超过 5 个词**（约 25 字符）；可以分 2–3 行，可以标题党：感叹、反问、断言、极端词都行
  （参考同事给的爆款示例：「印度徹底廢了！結構性清零！只能等死？」——三行短句、感叹 + 反问、情绪拉满）。
- 每期 **2–3 套**，对应 3 个推荐标题。封面喊最炸的那一句，标题讲完整冲突；可以和标题部分重复，不再要求三级递进。
- 有能一眼看懂的数字就放（`$50B GONE`），没有也不硬塞。

**② 提示词（Claude 写，给方向不给版式）**

```
YouTube thumbnail, 16:9, for the finance channel "[频道名]".
Video title: [推荐标题]. The story in one line: [事件 + 冲突].
Put this headline on the thumbnail, big and exactly as written: "[封面大字]"
Goal: it must pop like a roadside ad, not a piece of art — extreme contrast, strong emotion,
readable at phone size, one dominant subject. Bold clashing colors (yellow with black, red with white) work well.
[有人设形象图时] The host is the person in the reference image: keep the face consistent; expression and pose fit the story.
No real company logos or TV channel logos. Keep the bottom-right corner clear (duration label).
Everything else is up to you.
```

- 中文封面把模板换成中文，意思不变。除了上面几行，**不加构图、位置、字体、配色比例之类的指令**，让模型先发挥；出图不满意再针对具体问题补一句，不要一上来写满。

**③ 仍然要守的（技术和安全底线）**
- 〔必须〕**人像**：人设目录有形象图（如 `1-视频稿/_人设/Andy人设/形象/`）时，形象图作为参考图传给生图模型（qwen `--image`，Codex 在提示词里附图路径）；没有形象图的人设不放主持人脸。真人照片（高管、政客）不进封面。
- 〔必须〕**用生图模型整张生成**：Codex（`npm run image-codex`，英文字准、不乱编，英文封面优先）或 qwen-image-3.0-pro（`npm run image`），不用 Remotion / HTML 排版，不套片内视频风格。
  qwen 生成封面**必须开提示词改写**（不加 `--no-rewrite`），否则会把提示词原文印到画面上（参数见根目录 AGENTS.md「生图」）。从 Bash 调用，提示词放文件里用 `"$(cat 文件)"` 传。
- 〔必须〕**出图逐张核对**：封面大字和提示词里写的一字不差（错字、漏字、重复词都不用）；模型自己加的数字或说法不用。
- 〔必须〕尺寸 1280×720（Shorts 9:16 时关键信息放中间安全区），JPG < 2MB；右下角留给时长标签。
- 〔建议〕缩到手机推荐流大小（宽 168px）看一眼：1.5 秒内能看清大字、看出情绪。
- 交付时在 `发布包装.md`「封面」写：封面大字（2–3 套）、提示词文件、用的模型、核对结果、168px 检查。

### 5. 交付和评分

- 每期 **5–8 个候选标题**，**以点击冲击力为第一目标**，优先套爆款标题公式（K1–K6），标题党、强情绪、夸张、悬念都可以；建议 28–60 字符，不限用词。
- 选 **3 个推荐**用于「测试与比较」：建议 3 个用不同打法（只换几个字测不出差别），把你最看好的放第一个（M5：无结论时用第一个）。
- 下面的评分表是可选参考，不再有“低于 7 分不推荐”的门槛。

| 项（每项 0–2 分，满分 10） | 0 分 | 1 分 | 2 分 |
|---|---|---|---|
| 具体性 | 没有具体元素，或有弱认知实体 | 有强认知主体 | 强认知主体 + 数字或冲突 |
| 钩子强度 | 陈述句、说明文，没有好奇点 | 有好奇点但常见 | 让人"想知道答案"或"觉得和我的持仓有关" |
| 前 12 字宽 | 关键信息在后半段 | 有主体但没冲突 | 主体 + 冲突 / 数字（事件型：搜索词 + 冒号后冲突） |
| 兑现度 | 正文答不上 | 有答案但在很后面 | 开头 30 秒就开始兑现 |
| 干净度 | 有 T6 禁用词或两个无关噱头 | 稍长（> 26 字宽）或符号偏多 | 简洁、口语、无夸张 |

## 二、开头（前 25–28 秒，≤ 135 字口播）

MiMo 冰糖约 290 字 / 分钟，再留出数字停顿和转场，开头控制在 135 字以内。

### 1. 〔必须〕硬性要求

| # | 要求 |
|---|---|
| H1 | 第一句不能是寒暄、自我介绍、"今天我们来聊聊""最近很多人问我"、背景铺垫 |
| H2 | **第一句是钩子，兑现标题并多给一层信息**（标题没写的具体公司名、数字或动作）；不原样重读标题（M6） |
| H3 | 前 60 秒口播不说"欢迎来到 / 我是……"；频道和真实资历改成画面左下角名片条（0:08–0:15 出现约 4 秒），内容按所选人设，由脚本阶段标注 |
| H4 | 不机械报目录（"今天分五点：第一……第二……"）；清单型和一周前瞻可以在开头最后一句**用一句话串起不超过 3 个看点** |
| H5 | 不讲历史背景、不下定义；英文人名和机构全称不进前 30 秒口播（放画面字幕条） |
| H6 | **逗号分句 ≤ 20 字，整句 ≤ 40 字**，一句只讲一层意思；读出来不拗口 |
| H7 | 不用"某大厂""某神秘资金"这类盲盒词；第一句可以用"最大客户"这类关系标签承接标题，但**前 15 秒内必须点名**；公司类题材前 100 字至少 2 个具体公司名（美联储、非农等宏观题材不适用） |
| H8 | 不用 AI 连接废话：更值得注意的是、众所周知、不可否认、这背后的逻辑是、问题是、今天我们从……拆出；删掉后句意不变的连接词一律删 |
| H9 | **四个要素必须齐**：钩子、和观众的利害、信源、核心追问；**第一句是钩子，最后一句是进第一章的追问**，中间顺序可以灵活。**长视频 v4 起改为〇.5 O4 五要素**（加好处、悬念） |
| H10 | 事件型开头可以第一句给出结论方向，但**下一句必须用"但 + 关键变量"抛出反差**，不能一开头把底牌亮完 |

### 2. 〔建议〕做法

- **默认节奏**：0–6 秒钩子（25–30 字）→ 6–16 秒利害 + 反差数字（45–50 字）→ 16–28 秒信源 + 追问（45–55 字）。
  连续几期都一样会有套路感，可以把信源嵌进第一句（"摩根士丹利刚算了一笔账：……"）。
- **利害面向一类持仓**，不只面向一只股票（"只要你持有美股 AI 股"比"如果你手里有英伟达"覆盖更多人）。
- **数字说清口径**：毛利率还是毛利额、营收占比还是利润占比、哪个财年 / 季度；口播里含糊的数字比没有数字更伤信任。
- **信源一句带过**："伯恩斯坦的半导体分析师刚在行业会上算了这笔账"；人名放字幕条。
- **追问落到投资者利益**：不只是"能替代多少"，而是"会抢走多少订单、利润流向谁"。
- **自检**：逐句标功能（钩子 / 利害 / 信源 / 追问 / 无功能），"无功能"的句子删掉或后移；数字数 ≤ 135。

### 3. 〔必须〕交给脚本阶段的画面要求（写进视频稿备注）

- 前 5 秒至少 2 次视觉信息递进（如 0–2 秒冲突大字卡 → 2–5 秒巨头产品 / 人物画面），同一静态画面不超过 2.5 秒；
  静音只看画面和字幕也能看懂核心冲突（R2：首页静音自动播放）。
- 名片条的出现时间（H3）。

## 三、正文与留存（〔建议〕，视频稿阶段对照）

> v4 起长视频的正文结构以〇.5 的 S1–S5、R1–R4、E1–E3、D1–D4、C1–C4 为准（〔必须〕）；本节是补充写法。

- **双层节拍**：
  - **小节拍，每 35–45 秒（约 170–210 字）**：一次注意力刷新——算账举例、图表变化、反方观点、一个具体数字的"翻译"。
  - **大钩子，每 2–2.5 分钟（约 550–700 字，一般在章节交界）**：给出本章结论后，用一个推翻顺向思维的转折问题引出下一章。
  - 不要每 60 秒硬卖关子，会打断算账逻辑、显得像营销号。
- **章节**：按观众的问题分章，**章节名带公司名或业务关键词**（"谷歌 TPU 能替代多少英伟达 GPU？"，不写"替代比例测算"），
  用于 YouTube 章节（M8）和脚本阶段分镜。
- **数据三要素**：金额带币种；估值、增速、股价带时间基准（"按 2026 财年三季报""未来 12 个月市盈率"）；
  关键数字带对比标尺，并跟一句"这意味着什么"。
- **观点要有立场**：每章结尾给明确判断（"我的判断是……"），并说清风险或反方观点。
- **中段订阅提醒**：放在第一个高价值结论之后（约全片 30–40% 处），一句话（〇.5 C3）。
- **结尾**：按〇.5 C1–C4：判断 → 一个可执行的观察指标 → 站队式留言问题 → 明确喊订阅 → 免责声明；
  核心结论不能留到结尾才第一次讲。
- **长度**：MiMo 冰糖约 290 字 / 分钟；10 分钟约 2800–3000 字；v4 目标 15–25 分钟 ≈ 4300–7200 字。
