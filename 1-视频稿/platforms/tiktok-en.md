# TikTok 标准：英文版 v0

适用：已确认人设的英文财经 TikTok。可直接选题，也可从已确认的长视频成稿改编。
本文件是项目起步规范；**时长、字数、文案长度和安全区不是声称已核实的官方最佳值**，需在 App 预览和发布数据中校准。

## 〇、来源模式

- **直接选题**：走工作流①–⑩，使用标准 `01-初稿.md`、`02-外部建议.md`、`03-终稿-en.md`。
- **长视频改编**：源头是已确认的长视频英文成稿；只能删、合并、换说法，不增加新事实、数字或判断。
- 一条只讲一个值得评论或转发的结论，必须独立看懂，不写 “Part 1/2” 强迫连续观看。

## 一、稿件规则（起步值）

| 项 | 规则 |
|---|---|
| 时长 | 目标 35–75 秒，硬上限暂设 90 秒；以内容完整和实际配音为准 |
| 词数 | 约 90–180 个英文词，按约 150 词/分钟估算 |
| 首句 | ≤ 15 词，强认知主体 + 冲突或数字；第 0–1 秒同步出字卡 |
| 结构 | 钩子 → 一个关键数字 → 反转 / 算账 → My take → 评论问题或主页长视频引导 |
| 句子 | 每句 ≤ 15 词；数字之间隔一句；整条不超过 4 个核心数字 |
| 转发点 | 尽量有一句可截图转发的对比或结论，但不能为了冲突夸大事实 |
| 合规 | 免责声明不口播；文案末尾和最后一秒小字写 `Not investment advice.` |

禁用：Wait for it、You need to see this、Hey guys、In this video、SHOCKING、INSANE、Part 1/2，以及其他平台的订阅口播和水印。

## 二、信源与事实

- 信源规则与 `../AGENTS.md` 相同；直接选题也必须记录真实来源。
- 改编不新增长视频没有的事实。要改事实或判断，回视频稿阶段处理并重新确认。
- 有争议的数字在画面或文案写清日期、口径和来源，不用“大家都在说”代替证据。

## 三、交给脚本与制作阶段的画面要求

- 9:16，1080×1920，30fps；全程烧录英文字幕。
- 第 0–1 秒有钩子字卡；优先实拍、个股 / 财报截图、产品录屏和简洁图表，避免只有抽象科技背景。
- 字幕和关键信息先按保守安全区避开底部约 670 px、右侧约 120 px；**导出前必须在 TikTok 实际预览中检查**，不同界面和文案长度可能改变遮挡。
- 首帧关键信息尽量放中间 1080×1440，防止个人主页和 feed 裁切。
- 不带 YouTube、Instagram 等平台水印或订阅动画；第三方片段每段 ≤ 3 秒，并叠解说和字卡。
- 音乐使用自己的配乐库，不依赖平台热门音乐；人声始终清楚。

## 四、发布包装

直接选题保存为 `04-发布包装-tiktok-en.md`；长视频拆条时可放对应短视频子目录。

- 文案第一行写钩子 + 公司 / 代码，尽量控制在约 125 字符内（起步值，待实测）。
- 正文 3–5 行：补来源或一个口径说明，结尾问一个具体的问题，末尾 `Not investment advice.`。
- 话题标签 3–5 个，只放公司、代码和主题；不用 `#fyp`、 `#viral` 代替内容定位。
- 封面大字 3–5 个英文词，数字和公司名与成稿一致。

## 五、复盘

记录播放、平均观看时长、平均观看比例、跳过情况（有数据时）、分享、收藏、评论、新增关注和流量来源。攒 5–10 条后比较钩子、长度、分享和评论，再调整本文件。

## 六、成稿自检

- [ ] 人设和平台设置已确认，来源模式明确
- [ ] 事实、数字、信源和判断强度已核实；改编稿没有新增事实
- [ ] 一条只讲一个点，首句 ≤ 15 词，第 0–1 秒字卡已备注
- [ ] 词数、句长、数字数量和结构符合本文件或有明确理由
- [ ] 没有其他平台口播、水印、营销和 AI 填充词
- [ ] 全程字幕、安全区、授权和第三方片段要求已写入交接备注
- [ ] 用户人工修改并确认成稿
