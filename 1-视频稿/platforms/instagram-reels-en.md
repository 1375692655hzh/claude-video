# Instagram Reels 标准（英文，从长视频改编）

适用：已确认人设在 Instagram 发布的英文 Reels（竖屏短视频）。可直接选题，也可从审核通过的长视频英文成稿改编；每条只讲一个点。
**这份文件只写和长视频不同的地方**：默认财经信源规则（见 `../AGENTS.md`「信源规则」）、数字写法和单位换算、去 AI 味（`youtube-long-en.md` 第四、五节）照用。
标记含义同 `youtube-long.md`：〔官方〕平台机制、〔必须〕本项目硬规则、〔建议〕优先这样做。

> 版本 v1：纳入十步工作流，允许直接选题；保留从长视频拆 2–3 条的来源模式。**数字都是起步值**，等有 Insights 数据再调；
> 〔官方〕一栏是 2026-10-29 查到的媒体转述和平台公告，Instagram 官方创作者页（creators.instagram.com）本机抓不到，**待在 App 或官网原文核实**。

## 一、稿怎么来（〔必须〕）

- **直接选题**：走工作流①–⑩，使用标准 `01-初稿.md`、`02-外部建议.md`、`03-终稿-en.md`；事实按本项目信源规则核实。
- **长视频改编**：源头是审核通过的长视频 `<期名>/03-终稿-en.md`（有中文 `03-终稿.md` 时事实以它为准）。只能删、合并、换说法，**不加长视频没有的事实、数字和判断**。
- **一条 Reel 一个点**：挑观众最可能转给朋友的结论（反常识、算账、一个惊人的数字）。长视频一期拆 2–3 条时，互相不重复核心数字。
- 长视频拆条的文件放 `<期名>/ig/`：`01-reels稿-en.md`（所有条目写在一个文件，编号 R1、R2…）、`02-发布包装-en.md`、`cover/`、`工作量记录.md`。
- 改编稿每句英文下面附一行中文意思，方便用中文审逻辑（不另写中文底稿）；直接选题按项目设置决定是否保留中文底稿。

## 二、长度和结构

| # | 要求 |
|---|---|
| R1 〔必须〕 | **35–75 秒**，硬上限 90 秒；按 150 词/分钟估 **90–180 词**（MiMo 英文实测后按实测改） |
| R2 〔必须〕 | **第 1 句就是钩子**（≤ 15 词），带强认知主体 + 冲突或数字；不铺垫、不自我介绍、不说 "Hey guys" / "In this video" |
| R3 〔必须〕 | 结构五段：**钩子 → 一个关键数字 → 为什么（反转或算账）→ My take → 收尾追问或引导**；每段 1–3 句 |
| R4 〔必须〕 | 每句 ≤ 15 词；数字之间隔一句；整条不超过 4 个数字（多了观众记不住，也不好转发） |
| R5 〔必须〕 | 结尾一句引导二选一：评论追问（"Opportunity or trap? Tell me below."）或长视频（"Full breakdown on YouTube, link in bio."）；不说 "like and follow for more" |
| R6 〔建议〕 | 结尾句能接回开头（循环播放时不突兀），能加重复观看 |
| R7 〔建议〕 | 一句"可以截图转发"的话：一个对比数字或结论，配满屏字卡（对应 IG1 的 sends） |
| R8 〔必须〕 | 免责声明不口播，写在文案末尾和画面最后 1 秒小字：`Not investment advice.` |

禁用说法同 `youtube-long-en.md` H8-en、T6-en，另加：`Wait for it`、`You need to see this`、`Part 1/2`（每条要能独立看懂）。

## 三、交给脚本阶段（⑥–⑨）的画面要求（〔必须〕，写进 Reels 稿备注）

- 9:16，1080×1920，30fps；**全程烧录字幕**（逐词或逐句高亮），字幕放画面中间偏下，不进底部 670 px、右侧 120 px。
- 第 0–1 秒就有画面字卡（不用等口播），字卡内容 = 钩子的数字或冲突。
- 封面帧：关键信息放中间 1080×1440（3:4 网格）里，最稳是 y 285–1250 px 这一段。
- 不放 YouTube 台标、频道水印、"Subscribe" 动画；第三方视频片段每段 ≤ 3 秒且叠解说和字卡（IG3）。
- 名片条可选（短视频不一定要），用的话同长视频两行，只放开头 1–2 秒内之后。

## 四、发布包装

直接选题保存为 `04-发布包装-instagram-reels-en.md`；长视频拆条保存为 `ig/02-发布包装-en.md`。

| # | 要求 |
|---|---|
| P1 〔必须〕 | **文案第一行 ≤ 125 字符**（折叠前能看到的部分，数值待实测），写钩子 + 公司和代码：`Alphabet (GOOGL)` |
| P2 〔必须〕 | 文案正文 3–5 行：补一个片里没说完的数字或来源，结尾一个问题；末尾 `Not investment advice.` |
| P3 〔必须〕 | 话题标签 3–5 个（IG4）：公司 / 代码 / 主题各一，如 `#googl #alphabet #aistocks`；不用 `#fyp` `#viral` |
| P4 〔必须〕 | 封面 1080×1920，大字 3–5 个英文词，放 3:4 安全区；英文封面优先 Codex 生图（见总说明），或直接取片内字卡帧 |
| P5 〔建议〕 | 首发用 Trial reels（IG5），24–72 小时看数据再决定是否推给粉丝 |
| P6 〔建议〕 | 音乐用自己的配乐（`public/library/music/`），不用平台热门音乐（版权和原创性都更稳） |
| P7 〔建议〕 | 和长视频同期发：Reels 先发引流，主页链接指向 YouTube 长视频 |

## 五、发布后复盘（`ig/05-复盘.md`，有数据时填）

每条记：播放量、平均观看时长 / 片长、跳过率（Insights 有的话）、分享（sends）、收藏、点赞、评论、新增关注、是否 Trial。
攒 5–10 条后看：哪种钩子（反常识 / 算账 / 数字）分享率高，长度和平均观看比例的关系，再改第二节的数字。

## 六、自检（贴在 `ig/01-reels稿-en.md` 每条末尾）

- [ ] 直接选题的事实、数字和信源已核实；改编稿的所有事实、数字都在长视频成稿里有，判断强度没变
- [ ] 点名的信源都在信源规则名单里
- [ ] 第 1 句是钩子（≤ 15 词，主体 + 冲突 / 数字），没有自我介绍
- [ ] 五段结构齐；每句 ≤ 15 词；数字 ≤ 4 个；口播数字按读法写
- [ ] 词数在 90–180，估算时长 35–75 秒
- [ ] 结尾引导是 R5 的一种；没有禁用说法
- [ ] 画面备注写了 0–1 秒字卡、可截图字卡、安全区
