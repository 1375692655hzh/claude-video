# 标题与开头句式（参考模板）

配合 `platforms/youtube-long.md` 使用。模板只是起点：**每期至少有一个推荐标题不是直接套模板**，连续几期同一句式会有套路感。
`[ ]` 是占位符；示例里的数字只演示句式，**不是事实**，用时以当期稿件和核实过的数据为准。

---

## 一、标题句式

### 话题型（首页 / 推荐为主，钩子优先）

| # | 钩子 | 句式 | 字宽 | 示意 |
|---|---|---|---|---|
| A1 | 算账悖论 | `[主体 代码] 一年砸 [金额+币种] 投 [业务]，钱从哪赚回来？` | 19–24 | 微软 MSFT 一年砸 [X] 亿美元建数据中心，钱从哪赚回来？ |
| A2 | 反常识 / 替代 | `一边狂买 [A 的产品]、一边自研替代，[客户] 在算什么账？` | 22–26 | 一边狂买英伟达、一边自研芯片，谷歌在算什么账？ |
| A3 | 反常识 / 客户 | `[主体] 最大的客户，为什么在 [动作] 替代它？` | 18–24 | 英伟达最大的客户，为什么在自研芯片替代它？ |
| A4 | 持仓两难 | `[板块/公司] 跌到 [数字] 倍市盈率，便宜还是陷阱？` | 18–24 | 存储股跌到 [X] 倍市盈率，便宜还是陷阱？ |
| A5 | 业绩背离 | `[主体 代码] 营收大涨 [数字]%，为什么股价反而跌？` | 20–25 | [公司] 营收大涨 [X]%，为什么华尔街反而砍估值？ |
| A6 | 利益转移 | `AI 的钱正在从 [A] 流向 [B]，[持仓] 要不要换？` | 20–26 | AI 的钱正在从 GPU 流向 [B]，你的芯片股要不要换？ |
| A7 | 人物观点 | `[身份标签]：[一句反常识判断]` | 16–24 | 华尔街半导体分析师：AI 利润正在换手 |
| A8 | 清单 | `[强主体]之外，[板块] [数字] 个最容易踩的坑` | 16–22 | 英伟达之外，AI 算力链 5 个最容易踩的坑 |

### 事件型（搜索 + 推荐，搜索词在前，冒号后必须有冲突）

| # | 句式 | 示意 |
|---|---|---|
| B1 | `[事件]：[表面共识]，但 [具体指标] 藏着风险` | 英伟达三季报：营收超预期，但 [指标] 藏着风险 |
| B2 | `[事件]：[反差条件]，[人物] 还会 [动作] 吗？` | 美联储 11 月议息：通胀反弹，鲍威尔还会降息吗？ |
| B3 | `[公司A][公司B][公司C] 同周财报，[一个关键问题]` | 微软谷歌亚马逊同周财报，AI 投入到底回本没有？ |
| B4 | `[栏目事件] [数字] 件事，[最大的那件] 最关键｜美股一周前瞻` | 下周 3 件大事，[事件] 最关键｜美股一周前瞻 |

### 不合格对照

| 标题 | 问题 |
|---|---|
| 美联储 11 月议息：降不降息，对美股意味着什么 | 事件型写成说明文，冒号后没有冲突（T2、评分"钩子强度"0 分） |
| 重磅！AI 泡沫要破了？散户必看 | T6 禁用词，两个噱头，没有具体主体 |
| CASPA 大会上 Dylan Patel 讲了什么 | T3 弱认知实体 |
| 深度解析 AI 产业链利润分配的底层逻辑 | 无具体元素，AI 腔，T11 问的不是观众的问题 |
| 没人告诉你的英伟达真相 | T6 神秘感好奇词，没有数据锚点 |
| 微软砸 800 亿建机房 | T9 缺币种；"机房"不贴合投资者用词 |
| Andy's Market Lens：英伟达财报解读 | T10 频道名进标题；没有冲突 |

## 二、封面 → 标题 → 首句：三级递进

每期把这三样并排写一行，检查每一级是否多一层信息：

| 封面大字（4–6 字） | 标题 | 开头第一句 |
|---|---|---|
| 大客户反水？ | 英伟达最大的客户，为什么在自研芯片替代它？ | [点名 2–3 家客户]，正在花大钱造自己的芯片，替代英伟达。 |
| 钱从哪来？ | 微软一年砸 [X] 亿美元建数据中心，钱从哪赚回来？ | 微软今年砸进数据中心的 [X] 亿美元，比它 [对比标尺] 还多。 |
| 便宜是陷阱？ | 存储股跌到 [X] 倍市盈率，便宜还是陷阱？ | [公司] 现在的市盈率只有 [X] 倍，比它 [历史 / 同行] 低一大截。 |

## 三、开头句式（≤ 135 字，第一句钩子、最后一句追问）

### C1 话题型（默认节奏）

```
[钩子：点名的主体 + 冲突动作 / 数字，比标题多一层]
[利害：只要你持有 [一类股票]，这件事比 [常见关注点] 更关键。]
[反差数字：[数字 + 口径 + 对比标尺]。]
[信源 + 追问：[身份标签] 刚在 [场合] 算了这笔账：[追问，落到订单 / 利润 / 估值]？]
```

示意（数字为占位）：
> 微软、谷歌和亚马逊，正在花大钱造自己的 AI 芯片，替代英伟达。
> 只要你持有美股 AI 股，这件事比下一份财报更关键。
> 英伟达 [X]% 的营收，来自这几家大客户。
> 伯恩斯坦的半导体分析师刚在行业会上算了这笔账：自研芯片会抢走英伟达多少订单？利润又会流向谁？

### C2 信源前置（换节奏用）

```
[信源 + 钩子：[机构/身份] 刚算了一笔账：[主体] [动作]，[反差结果]。]
[利害：……]
[追问：……]
```

### C3 事件型（先给方向，紧跟"但"）

```
[方向：直接回应观众搜的问题，[事件] 大概率 [结论方向]。]
[反差：但真正决定 [持仓 / 市场] 的，不是 [表面结论]，而是 [关键变量]。]
[利害 + 数字：……]
[追问：[关键变量] 会怎么走？]
```

示意：
> 这次议息，美联储大概率按兵不动。
> 但真正决定美股接下来怎么走的，不是降不降息，而是鲍威尔怎么说 [关键变量]。
> ……

### C4 清单型 / 一周前瞻（允许一句话串起 ≤ 3 个看点）

```
[钩子：下周最可能 [影响] 的，是 [最大事件]。]
[利害：……]
[串看点：再加上 [事件 2] 和 [事件 3]，下周 [市场] 要连过三关。]
[追问：第一关 [事件] 会不会 [风险]？]
```

### 不合格对照

> 大家好，欢迎来到 Andy's Market Lens。最近 AI 很火，很多朋友问我怎么看。今天我们从五个角度来拆解。

H1 寒暄、H3 自我介绍、H5 背景、H4 报目录、H8 "今天我们从……拆解"，五句里没有一句有功能。

> 英伟达最大的客户，正在花钱造芯片替代它。

单看没错，但和标题"英伟达最大的客户，为什么在自研芯片替代它？"几乎一样（H2 没多一层信息），也没点名（H7）。
