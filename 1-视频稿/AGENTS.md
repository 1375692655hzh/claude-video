# 第 1 步：视频稿

把用户给的选题或素材，写成一份可以直接口播的视频稿，并在审核通过后做发布包装。
**频道只发英文视频**（2026-10-29 起）：先写中文底稿（`01`–`03`，用户用中文审逻辑和事实），再改写成发布用的英文稿 `03-终稿-en.md`，发布包装只做英文版。规范：`platforms/youtube-long.md`（通用规则 + 中文底稿）+ `platforms/youtube-long-en.md`（英文稿和英文包装，以它为准）；账号英文基础信息见 `_人设/Andy人设.md`（只用频道名、Handle、频道简介，其余内容不采用）。
目前只做 **YouTube 长视频**；以后加 Shorts、B 站、Instagram 时在 `platforms/` 新增规范。
整个工作流的分工和交接见上一层 `../AGENTS.md`。

## 目录

```
platforms/youtube-long.md   YouTube 长视频爆款标准：〔官方〕机制 / 〔必须〕规则 / 〔建议〕做法 + 自检清单——每期都要对照
standards/去AI味.md          去 AI 味的综合清单（humanizer + humanizer-zh + 口播补充）
templates/                   视频稿模板、发布包装模板、标题与开头句式（参考模板和合格 / 不合格对照）
consult/                     问 agy 的提问模板
_人设/Andy人设.md            账号英文基础信息（频道名、Handle、简介），其余内容不采用（用户的腾讯文档 https://docs.qq.com/doc/DQUdoVURwVWJ4eUF2，改了重新 fetch-doc）
_参考稿/                     用户认可的历史稿件（CASPA 大会稿、一周前瞻），用作文风样本，只学语气和节奏
<期名>/                      每期一个文件夹，期名格式 YYYY-MM-<英文短名>，如 2026-11-ai-profit；第 2、3 步沿用同一个期名
```

## 流程（每个阶段一个文件，逐步推进）

| 阶段 | 产出（`<期名>/` 下） | 做法 | 停下等用户？ |
|---|---|---|---|
| 0 选题与素材 | `00-选题与素材.md` | 记录用户给的选题、链接、录音、要求；腾讯文档用 `npm run fetch-doc -- <链接> <期名>/素材-xx.md` 拉下来 | 选题不清楚时问 |
| 1 初稿 | `01-初稿.md` | 按 `templates/视频稿模板.md`；事实和数据要有出处，不确定的标出来 | 否 |
| 2 爆款优化 | `02-爆款优化.md`、`02b-agy建议.md` | ① Claude 按 `platforms/youtube-long.md` 逐条改（句式参考 `templates/标题与开头句式.md`），附修改清单、第七节自检清单和标题评分；② `npm run consult` 让 agy 给第二意见；③ Claude 合成，写明采纳 / 驳回理由 | 否 |
| 3 去 AI 味 | `03-终稿.md`（中文底稿） | 用 humanizer-zh skill，以 `_参考稿/` 为文风样本，再按 `standards/去AI味.md` 的口播补充清单自检，附命中清单；数字、人名、引用、判断强度不改 | **是：交用户审核** |
| 3b 英文稿 | `03-终稿-en.md` | 按 `platforms/youtube-long-en.md` 从中文底稿改写（不是直译），`humanizer` skill 去 AI 味；可选 agy 审（命令见下） | **是：交用户审核** |
| 4 发布包装 | `04-发布包装-youtube-en.md`、`cover/` | 英文稿审核通过后，按 `templates/发布包装模板.md` 和 `youtube-long-en.md` 第六节做英文版：标题候选 + 3 个推荐、封面 2–3 版、简介、置顶评论、标签 | 交付后请用户选标题和封面 |
| 5 复盘（发布后） | `05-复盘.md` | 用户给后台数据（曝光、点击率、前 30 秒留存、平均观看比例、测试与比较结果），按 `youtube-long.md` 第五节记录；攒 3–5 期后调整标准 | 用户提供数据时做 |

## 信源规则（必须，所有语种、口播和画面字卡都适用；2026-10-29 用户定）

- **口播和字卡里能点名的信源只有三类**：知名投行（高盛、摩根士丹利、摩根大通、美银、花旗、瑞银、伯恩斯坦等）、
  知名研究 / 数据机构（彭博、LSEG、FactSet、皮尤研究中心、Gartner、IDC 等）、金融和企业界名人（巴菲特、黄仁勋、皮查伊等）。
  公司自己的财报、SEC 文件、电话会和管理层原话是一手资料，一直可以用。
- **其他来源不点名**：海豚研究、长桥、华尔街见闻、富途、公众号、自媒体、财经资讯站都不在名单里，口播里也不能说"有机构认为"来暗指它们。
  它们只能当线索：给出的事实要用财报或上面三类信源核实后再用（按核实到的那个来源署名）；它们自己的测算、调研、推断（买方预期、
  延期传闻、估值倍数等）核实不到就删掉，不改头换面说成"市场普遍认为"。
- 稿内的"（来源：……）"标注写真实出处，方便核对；不口播。没有具名的"市场一致预期"可以用，但要在标注里写清是谁统计的（拿不准就写"多家媒体报道的一致预期"）。

## 英文稿（发布用）

中文 `03-终稿.md` 审核通过后，按 `platforms/youtube-long-en.md` 改写出 `<期名>/03-终稿-en.md`（改写不是直译，事实以中文稿为准），
`humanizer` skill 去 AI 味，可选用 `consult/爆款优化-提问-en.md` 请 agy 审：
`npm run consult -- consult/爆款优化-提问-en.md --file <期名>/03-终稿-en.md --file <期名>/03-终稿.md --file platforms/youtube-long-en.md --file platforms/youtube-long.md --out <期名>/03b-agy建议-en.md`。
英文视频单独发布（不是中文视频的音轨）。

审核通过的 `03-终稿-en.md` 就是第 2 步的输入（中文 `03-终稿.md` 一起交，供理解内容）；改稿要回到这一步改：先改中文底稿，再同步英文稿，不在第 2、3 步里改口播文字。

## 常用命令（在本文件夹运行）

| 用途 | 命令 |
|---|---|
| 拉腾讯文档（正文 + 图片） | `npm run fetch-doc -- <链接> <期名>/素材.md` |
| 问 agy 第二意见 | `npm run consult -- consult/爆款优化-提问.md --file <期名>/02-爆款优化.md --file platforms/youtube-long.md --out <期名>/02b-agy建议.md` |
| 生成封面（整张，提示词只给内容） | 从 Bash：`npm run image -- "$(cat 提示词.txt)" <期名>/cover/A-en.png --size 1920*1080 --n 2` |

agy 默认用 Gemini 4 Argon High（`--model` 可换，`agy models` 查列表），一次 30 秒到几分钟，只读不改文件。
