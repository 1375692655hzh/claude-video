# ajiang-video-broll 在本项目里怎么用

来源：`NanmiCoder/ajiang-vibe-coding-skills` → `skills/ajiang-video-broll`（MIT），锁定提交 `00608a6c0d9cc44f8bede165588ddfb4b82ec4c8`（2026-11-05 引入）。
原样保留，**不在这里改原文件**；本项目的适配都写在这份说明和下面列出的位置。升级时重新拷贝整个目录、更新 `skills-lock.json` 的 ref，再核对本说明。

## 它是什么

给**已经剪好的口播视频**做整屏 16:9 B-roll / MG 包装段落：输入 SRT + 时间段 → 选一套模板 → 预览页确认 → Remotion 渲染 4K → 配主题拟音和配乐 → 按 SRT 毫秒时间命名交付，用来盖住剪辑时间线上的视频轨。
它自带一套独立引擎（`assets/engine/broll-core.js`，字符串 HTML + `data-a` 声明式动画，预览和成片同一份代码）和 10 套模板（`assets/themes/<id>/`）。

## 和本项目的关系（两层接入）

1. **10 套模板 → 风格库**（日常用这一层）：每套模板的配色、字体、底纹 / 页眉、标题和大数字处理已移植成本项目的 StyleKit，
   和 cards / navy / deco 等并列，ID 直接沿用：`paper-signal`、`sticker-pop`、`mint-switch`、`warm-haze`、`sticky-audit`、`riso-print`、`showa-poster`、`retro-sunburst`、`color-cards`、`bauhaus-grid`。
   - 代码：`3-视频生成/effects/_shared/styles/broll-kits.tsx`（外观组件）、`_shared/motion/theme.ts`（动效库配色）、`styles/index.ts`（登记）。
   - 说明、样张、展示卡：`shared/style-library/<id>/`；选风格照常走 `style.mjs history / 预览.html / use`。
   - 移植的是“长什么样”。原模板里的**招牌版式和动效编排**（如 paper-signal 的橙色扫描条、riso-print 的套印错位、bauhaus-grid 的几何格翻转）没有逐一搬进 StyleKit——
     本项目的“怎么动”由动效库负责；需要原汁原味的版式时用第 2 层。
   - 字体换成英文版：原模板中文字体（Noto Sans SC 等）在本项目里换成同气质的拉丁字体，见各风格 `style.json` 的 `fonts`。
2. **完整 skill → B-roll 段落**（特殊情况用）：数字人 / 真人口播片需要“整屏包装段落盖在口播上”时，按 `SKILL.md` 原流程做，
   工程放在本期项目 `05-制作/broll/`（不放进 skill 目录、不放进 `3-视频生成/`），交付的 mp4 放 `06-交付/<平台>/broll/`。

## 用原流程时的本项目约定（覆盖 SKILL.md 里不适用的默认）

- **语言**：本项目发布英文。场景文案用英文成稿原句（不要中文），字体脚本 `fetch_fonts.py` 会按实际文字子集下载。
- **网页素材**：原文默认 ego-browser（本项目没有）。改用本项目素材流程：素材库 `assets.mjs` + 内置浏览器截图；官网截图、logo 照样登记在 `02-脚本/assets.md`。
- **logo**：lobehub 图标可用，但仍要守本项目信源规则（不点名的机构不出 logo）。
- **配乐音效**：原 skill 用 `audio_lib.py` 程序合成拟音和配乐；本项目片子统一走 `mix-audio.mjs` + 公共配乐音效库（`sfx-rules` 规范）。
  B-roll 段落混进本项目成片时，不另带配乐，只保留需要的拟音；单独交付 B-roll 段落时可用原 skill 的混音（-16 dB / 真峰值 ≤ -14 dBFS）。
- **Python 依赖**：numpy、scipy、soundfile、pyloudnorm、pillow（Linux 环境 `pip3 install --user ...`）。
- **渲染**：原 starter 用 remotion 4.0.534，与 `3-视频生成` 的版本可能不同，工程独立安装依赖；Linux 环境单条命令 3 分钟限制照旧（分段渲染）。
- **预览页确认 = 本项目的风格确认**：预览页发 Artifact 给用户确认后再渲染，和⑨的人工闸门对应。

## 主题库原页面（看原汁原味的动效）

`assets/gallery/build.py <输出目录>` 生成主题库页面（10 套同一段 12 秒演示、可单独回放每个动效、试听音效），可发布成 Artifact 给用户挑。
本项目风格库 `预览.html` 只展示移植后的静态样张。
