## 四、素材使用规则

- 只使用 `assets.md` 已关闭需求的素材；不能自行换成未核实链接或无关图片。
- 外部视频按素材库 ID + 精确片段下载；人工素材来自 `2-脚本/<期名>/材料/`，保持原文件并复制到工程 `public/<期名>/`。
- 生成素材只按脚本和用户批准的方案制作；不新编数据、信源、公司事实或主持人经历。
- 保留来源和授权信息，财报 / 行情截图核对公司、日期、单位和口径。

## 五、仓库承接结构

```text
3-视频生成/
  effects/<期名>/       本期 Composition、Main、场景、timeline、voice.json
  public/<期名>/        voice / host / img / video / doc 等实际素材
  out/<期名>.mp4        最终渲染
```

- 所有动画在本期目录注册到 `effects/index.tsx`，共用一套 Remotion 依赖，不新建独立工程。
- 配音后用 `ffprobe` 实测时长，再计算镜头、字幕和人声区间；不要只按估算词数锁死全片。
- 音乐、音效、数字人和渲染遵循 `3-视频生成/AGENTS.md`；涉及付费生成、积分或外部智能体时先由用户明确选择并确认。

## 六、交付与验收

- [ ] 先交付代表性关键帧 / 短段，用户确认后再做全片
- [ ] 动画只使用脚本成稿口播，字幕与配音一致
- [ ] 所有分镜都有真实素材或已批准的生成方案，无占位缺口
- [ ] 画面符合参考图继承项和所选平台安全区
- [ ] 代码回本期目录，不改历史期；运行 `npm run lint`
- [ ] 渲染后用 `ffprobe` 核对时长、帧率、分辨率和编码，并检查关键帧 / 短段
- [ ] 最终交付 `out/<期名>.mp4`，需要时同时交付字幕文件
