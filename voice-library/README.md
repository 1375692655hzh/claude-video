# 音色库

各家 TTS 的音色试听，用来挑配音。一个来源一个文件夹，文件名就是调用时用的音色 ID。

所有试听用同一段示例文字，方便横向对比：

> 大家好，欢迎收看本周美股前瞻。三大云巨头集中交卷，美联储决议也将揭晓，我们一起来看看。Welcome to this week's market preview.

## mimo/ —— 小米 MiMo TTS（`mimo-v2.5-tts`）

生成命令：`npm run tts -- "<示例文字>" voice-library/mimo/<音色>.mp3 --voice <音色>`

## 新增来源

1. 新建 `voice-library/<来源>/`（小写英文，如 `azure`、`qwen`）。
2. 用上面同一段示例文字，每个音色生成一个文件，文件名 = 音色 ID。
3. 在本文件里加一节，写清模型名、生成命令和音色表。
